# 智汇 AI 对接平台（AI Landing Hub）

> 免费、开源、中立的 AI 落地供需对接平台：企业 / 个人 / 工厂公开招标 AI 需求，个人开发者、独立工作室与专业企业团队展示档案与案例作品，直接对接。

平台不做竞价排名、不抽取交易佣金、不截留供需双方联系方式；代码以 MIT 协议开源，任何人都可以审查、复制并自部署。

## 功能清单

- **需求大厅**：关键词搜索，按需求方类型、行业、预算区间、期望技能、状态筛选，按最新 / 预算 / 浏览量排序
- **需求详情**：场景描述、预算 / 周期 / 地区 / 截止时间、技能标签、投标意向提交、相关开发者推荐
- **开发者目录**：按身份类型、技能方向、地区筛选，按评分 / 年限 / 完成项目排序
- **开发者档案**：简介、技能栈、服务方式、案例作品集（含交付结果）、合作意向提交
- **发布需求**：分组表单 + 校验，公开招标信息进入大厅
- **开发者入驻**：档案与案例动态录入，提交后生成公开档案
- **收藏**：收藏需求与开发者，本地保留
- **关于与开源**：愿景、平台原则、产品路线图、贡献方式
- 响应式布局（桌面 / 平板 / 移动端）、吸顶导航、移动抽屉、Toast 提示、模态弹窗、SPA 深链兜底

## 技术栈

- 原生 HTML / CSS / ES Modules，**零运行时第三方依赖**，无需 `npm install` 即可构建
- 手写 CSS 设计系统（CSS 变量、渐变、卡片、徽章、表单）
- Hash 路由（`#/projects`、`#/project/:id` 等）
- 本地持久化：`localStorage`（演示版）

## 快速开始

```bash
# 构建产物到 dist/（Node >= 20，无需安装依赖）
npm run build

# 本地预览生产构建（默认端口 4173，可传端口号）
npm run preview
# 或：node scripts/preview.mjs 4199
```

- 构建命令：`npm run build`
- 输出目录：`dist/`
- 无环境变量依赖（当前版本不接入任何云端服务）

## 数据层说明（重要）

当前为**前端演示版**：

- 内置种子需求与开发者档案；用户通过表单提交的内容、收藏与投标意向保存在**当前浏览器 localStorage**，不经过任何服务器。
- 因此换浏览器 / 清缓存后，本地提交内容不会保留；这是演示阶段的刻意降级，不是数据丢失故障。

后端接入规划（路线图）：

- 注册登录与身份资料、需求 / 档案持久化到数据库（Supabase / Neon 等）
- 投标留言、合作意向与消息通知
- 实名认证、案例审核、交付后评价体系
- 接入时遵循：连接串只存平台侧环境变量，前端不持有 service role / 主库密码。

## 部署

- 平台：静态托管（Cloudflare Pages / Vercel / Netlify 等任意静态站点）
- 构建命令：`npm run build`
- 输出目录：`dist`
- 环境变量：无（当前版本不配置密钥）
- SPA 兜底：产物已带 `_redirects`（`/* /index.html 200`）与 `404.html`

### 域名

- 默认使用托管平台分配的免费二级域名（如 `*.pages.dev` / `*.vercel.app`）。
- 绑定自定义域名时，在平台侧添加域名并按提示配置 CNAME；证书由平台自动签发。

### 回滚

- 代码：`git revert <sha>` 触发重新部署；
- 平台：在部署记录中选择上一个可用版本 Promote。
